# Reactive_Programming_Binding2

Лабораторна робота №1, частина 2. Приклади прив’язки CSS-класів і стилів в Angular.

## Запуск

```powershell
npm.cmd ci
npm.cmd start -- --port 4203
```

Відкрийте http://localhost:4203.

## Збірка

```powershell
npm.cmd run build
```

Результат: `dist/binding2/browser`.

## Вправи

- `task-6`: перемикач червоного блоку через `[class.isredbox]` і синій блок через `[class]`.
- `task-7`: усі приклади з вправи 6 і перемикач кольорів через `[style.backgroundColor]` та `[style.background-color]`.
